# Ruta 23 · Cuéllar y Tierra de Pinares

El [plano OSM](planos/ruta_23.svg), norte arriba, ubica el castillo en la zona alta de Cuéllar y los pinares alrededor. El mapa de aventura comprime las distancias en 64×40 casillas. San Miguel queda al este; Valladolid al oeste.

[Turismo del Ayuntamiento de Cuéllar](https://www.cuellar.es/castillo-de-los-duques-de-alburquerque/) documenta el castillo-palacio en la zona alta y su uso como instituto y archivo. [Los encierros](https://www.cuellar.es/encierros-de-cuellar/) sirven de referencia para el entrenador con Ponyta. © colaboradores de OpenStreetMap, ODbL.

## Estado (2026-10-09)

Castillo propio provisional (fuente 357), torre cuadrada y lienzo almenado: revisión de textura, volumen y escala pendiente Javier. Dos entrenadores genéricos; encuentros 47–50, sin premios ni famosos. Las puertas todavía no conducen a interiores.

Conexiones recíprocas: Valladolid este filas 30–33 → Ruta 23 oeste 18–21, offset −12/+12. Ruta 23 este filas 18–21 → San Miguel oeste 31–34, offset +13/−13. El cambio del pueblo inicial se limita al paso sobre el Duratón y el acceso occidental, autorizado para esta sesión. Se conservan casas, personajes, entradas y salida a Ruta 1.
